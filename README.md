The lattice-symmetries library provides tools for working with symmetry-adapted quantum many-body bases. It focuses on efficient implementation of core algorithms through vectorization and parallelization, enabling high-performance calculations for large quantum systems. The library offers a simple Python API that is generic enough to implement most state-vector based algorithms.
